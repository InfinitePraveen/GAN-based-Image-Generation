# Contributing

Thank you for considering a contribution to this project.

## How to Contribute

1. Fork the repository.
2. Create a new branch.
3. Make a focused change.
4. Test the notebook or Flask application affected by the change.
5. Update the documentation when the behavior changes.
6. Open a pull request with a clear description.

## Good Contribution Areas

- Improving notebook explanations
- Improving GAN training stability
- Adding useful visualizations
- Improving the Flask interface
- Fixing bugs
- Improving documentation
- Adding reproducibility notes

## Before Opening a Pull Request

Please check that:

- The notebook runs without avoidable errors.
- New code follows the existing simple project structure.
- No large dataset files are committed.
- Trained model checkpoints are not accidentally committed unless intentionally released.
- README or CHANGELOG is updated when appropriate.

## Style

Keep the code readable and beginner-friendly. Avoid unnecessary abstractions or extra modules for small changes.
